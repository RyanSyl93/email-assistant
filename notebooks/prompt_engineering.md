# Notes
We try to aim for Clear, Contextual and Actionable prompts.

# Four Pillars of Effective AI Prompting

## Persona (AI's Role)

Define the role you want the AI to Play (empathetic support aganet, technical troubleshooter)

## Task (Actions Required)

State the exact action you (write a reply, summarize a ticket, or analyze error log)

## Context (Background info)

Share the background information the AI needs (customer message, relevant policy text, or system logs)

## Format (Output Structure)

Specify how the response should look (bullet points, poliet email, JSON Block)

# Example

You are a program manager in [industry]. Draft an executive summary email to [persona] based on [details about relevant program docs]. Limit to bullet points
